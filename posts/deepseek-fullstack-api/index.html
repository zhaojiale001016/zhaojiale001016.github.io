DeepSeek 把自家 App 拆开卖：全家桶 API 开放，开发者可以直接 1:1 复刻官方应用

技术资讯 2026-11-15 约 9 分钟读完 · 阅读 - 次

11 月 13 日晚上 22 点 19 分，DeepSeek 官方公众号发了一则公告，标题朴素得有点反常——《DeepSeek 发布全家桶应用 API》。

图源：DeepSeek 微信公众号《DeepSeek 发布全家桶应用 API》

公告第一段就把话说透了：在 DeepSeek App 里面，联网搜索、文件输入、阅读链接、语音交互、安全校验这些能力，是和模型推理配合着跑出来的；但你想在自己的 App 里做出类似体验，除了接 API，还得自己去对接外部工具、处理调用衔接，“往往还需耗费大量精力”。

现在，这些胶水活儿，DeepSeek 帮你干了。

到底开放了什么

官方口径很清楚：deepseek-flash（也就是 V4.1-Flash）已经在 Messages、Responses、Chat Completions 三类接口下支持这些能力，工具调用和上下文拼接全部由服务端完成：

  • 联网搜索（deepseek_web_search）：非思考模式下，模型根据提问自动发起网页或图片搜索，并在回答里附上引用；思考模式下，模型能在多步推理中自主联网搜索、阅读链接，再结合拿到的信息继续推理。
  • 深度思考搜索：就是上面那条的加强版，重点在”多步推理中自主检索”。
  • 文件输入：PDF、Office 文档、图片，服务端完成纯文本提取或图文混排解析，拼进上下文。
  • 阅读链接（deepseek_read_url）：模型自动识别用户消息里的链接，抓取网页内容后结合上下文作答。
  • 模型安全：开启安全校验参数后提供基础风控，命中风险时返回拒答标识。

更关键的是，这些底层能力还支持作为独立接口单独调用：Search、Fetch、OCR、ASR、TTS。官方给的学习应用例子很直白——OCR 识别试卷，交给模型讲题；ASR 把语音转成文字，模型理解需求，TTS 再把答案念出来。

价格表比功能表更值得看

图源：DeepSeek 官方《DeepSeek 发布全家桶应用 API》

调用扩展能力，除了 Token 费用之外，还要按次收工具费：

项目价格
文字 / 图片搜索5 元 / 千次
网页抓取5 元 / 千次
文字识别（OCR）1.5 元 / 千页
语音识别（ASR）0.39 元 / 小时（原价 0.78，限时 5 折）
语音合成（TTS）1.5 元 / 万字符（原价 3.0，限时 5 折）

我自己算了一下账：一次典型的深度研究任务，模型来回搜索、读链接几十次很常见，搜索按 0.005 元一次算，单次研究光工具费就是几毛钱到一两块。这意味着一旦你的产品重度依赖联网搜索，工具费完全有可能盖过 Token 费本身，而且它是按调用次数走、不会因为你缓存了什么而变便宜。所以定价表不是附录，是核心参数。

还顺手送了个开源 Demo

DeepSeek 不只是开放接口，还用这套新 API 写了一个轻量对话客户端并开源，支持直接导入历史对话。

图源：GitHub 仓库页 deepseek-ai/chat-demo

仓库是 MIT 协议，star 数已经接近 600，fork 过百，版本停在 v0.1.1。官方给的体验入口是 cdn.deepseek.com/chat-demo。这个 Demo 的意义不在于产品，而在于它把”这套 API 到底能做出什么东西”变成了一个可以直接抄的起点——过去这层样板代码每个团队都要自己写一遍。

我怎么看这件事

第一，这是把”应用层胶水”标准化了，而且是最脏最累的那一层。

大模型 API 这两年卷得热闹，榜单分数早就不值钱了，真正的工程量早就转移到了模型周围那一圈：搜索引擎怎么接、PDF 怎么解析、工具调用的顺序怎么编排、上下文怎么拼、失败了怎么重试。这些活儿没有一件有技术含量，但每一件都能耗掉一个小团队两周。DeepSeek 这次等于官方承认了这一点，然后把这一圈打包成接口卖给你。

对独立开发者和小团队，这是实打实的成本削减：以前要做”能联网、能读文档、能说话”的完整应用，你至少得同时维护搜索、解析、语音三条外部供应链；现在是一个 Base URL。

第二，“1:1 复刻 DeepSeek App”这句话，比功能清单更值得琢磨。

DeepSeek Harness 负责人崔添翼在官方公告里写：“下一个超级 App 不必是面向所有人的一个超级 App。现在，每个人都有能力创造一个超级 App。下一个超级 App 也可以是只属于你一个人的超级 App。”

翻译一下：大厂正在主动放弃”封闭 App 护城河”这层防线，转而去做底座。对开发者是好事——你能用极低成本做出过去只有大厂才做得出的体验。但反过来想，套壳 DeepSeek 的门槛现在几乎为零，差异化必然从”能力”转移到”产品定义”。最后能活下来的不会是功能最多的那个，而是把一个具体问题解决得最狠的那个。

第三，有个成本不在定价表里，得自己算。

官方写得很明白：如果对外提供应用服务，应务必开启安全校验参数，并自行承担内容安全审核、大模型登记、AI 标识等义务。这部分的人力、备案、法务成本，没有任何一条 API 价格能覆盖。做 To C 的团队，这笔钱要提前算进模型。

第四，别被”全家桶”三个字带偏。

这次开放的本质是工具层的标准化，不是模型能力的跃升。V4.1-Flash 本身没变，变的只是它能看到的世界变大了。所以真正的价值取决于你把它接进什么工作流里——如果你只是把官网 Demo 跑一遍改个皮，那这套 API 对你和之前没有任何区别。
