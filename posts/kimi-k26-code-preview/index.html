Kimi K2.6-code-preview 上线：万亿参数模型挤进 39 元/月，AI 编程的价格战打到第二回合

技术资讯 2026-11-11 约 8 分钟读完 · 阅读 - 次

这周国产大模型的更新节奏有点密。GLM-5.1 开源、MiniMax 2.7 开源，然后是月之暗面的 Kimi K2.6-code-preview——一个专门为 AI 编程调校的万亿参数模型，11 月 11 日前后上的线。

但官方这次几乎没宣传。官网上只挂了一行”K2.6-code-preview 现已上线”，连”这次升级了什么”的说明都还没写全。反而是内测用户和各家媒体先把它扒了出来。

图源：快科技《国产万亿大模型再升级 kimi 2.6-code来了：AI编程新选择 月费39起》

先把价格说清楚，因为这是它最大的卖点

要用 K2.6-code-preview，前提是开 Kimi 的会员计划，起步 39 元每月，在 Kimi Code 里调用。

这个定价放在今天的市场里已经不算贵了。同期海外订阅 Claude / Codex 那一档的价格是它的好几倍，而且是美元。国产阵营这半年最明显的变化不是分数涨了多少，而是同一档能力的月费被摁着往下降了。

不过有个细节值得留意：K2.6-code-preview 是 K2.5 的改进版，而 K2.5 本身已经是万亿参数。K2.6 的开源版早在今年 4 月就发布过，当时主打的是长程编码——不间断写 13 小时、改 4000 多行代码，以及 300 个子 Agent 并行调度。所以 K2.6-code 并不是从零起的新模型，而是把通用版里”写代码”这条最吃算力的路径单独抽出来，做成付费订阅里能给到的形态。

分数到底多少？我更信这张表，但更信它的局限

官方没有公布榜单成绩，于是内测圈子里流传了一份第三方评测（作者自评，任务集和评分口径都没有公开）：

图源：快科技《国产万亿大模型再升级 kimi 2.6-code来了：AI编程新选择 月费39起》

表里 K2.6-code-preview 得 89 分，K2.5 是 83 分，涨了 6 分。排在它前面的是 KAT-Coder-Prev-2（97）、GPT-5.4（97）、Opus 4.6（95）、Qwen3.6 Plus Preview（95）、GLM-5（94）、Claude Sonnet 4.6（93.5）、GPT-5.3 Codex（92.5）、Gemini 3.1 Pro Preview（92）。Claude Sonnet 4.6 排在它前面一位。

内测者对这次升级的描述集中在三点：推理深度、Agent 的规划质量、以及多步工具调用时的可靠性。有开发者说它的思维链”有 Opus 的味道”——这评价有点微妙，意思是风格像，而不是水平追上了。

我的判断更直接一点：89 分和 83 分这 6 分差距，在真实工程里几乎没有体感。真正决定”好不好用”的，是它在一个真实仓库里连续跑三小时会不会跑偏、工具调用失败率多高、上下文吃紧的时候会不会降智。这些东西任何榜单都测不出来。而这份第三方评测表最大的问题是不可复现——任务集、评分脚本、样本量都没公开，读者没法验证它到底测的是什么。

已经用上的人怎么说

翻了一下社交平台上的实际反馈，评价偏正面但也说得很具体：

图源：快科技《国产万亿大模型再升级 kimi 2.6-code来了：AI编程新选择 月费39起》

被吐槽最多的不是能力，是节奏。“已经发布了，正在测试中感觉指令遵循还行”——注意”正在测试中”这几个字。一个刚上线的模型，用户给出的评价带着这么大的保留，说明它在指令遵循这类基础能力上大概率还没完全打磨好。

指令遵循恰恰是 AI 编程里最要命的环节。模型再聪明，一旦在长任务里漏掉一条约束（少改一个文件、忘记跑测试、没按你要求的文件结构输出），整个 diff 就得返工。K2.5 时代的对比数据是 SWE-Bench Verified 76.8%、LiveCodeBench 85%，K2.6-code-preview 的官方成绩目前还看不到，这块只能等。

所以我怎么看这个发布

三句话：

  1. 方向对了。把通用大模型里最值钱的能力单独做成订阅版本，是把推理成本精准定价到愿意付费的人群身上——你不需要它写诗写文案，你只需要它改代码，那就按代码任务算钱。39 元的定价很精明。
  2. 宣传跟不上。一次模型更新，官网连 changelog 都还没写清楚，用户靠社区扒出来才知道有这东西。这对开发者生态是慢性损耗——你把口碑做出来了，但没人第一时间知道，功能上线一周后的讨论度会掉一大截。
  3. 榜单别太当真。那张表是好用的参考，但不是结论。国产模型现在的问题已经不是”够不够强”，而是”在不同任务形态下的稳定性够不够”，这个只能靠你自己的仓库测。

如果你手上正好有能跑评测的仓库，39 块钱试一个月不亏。把它和订阅的 Claude Code 放一起，用同一批真实任务跑一遍，最后用你自己的代码库投票，比任何榜单都靠谱。
